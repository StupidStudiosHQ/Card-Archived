## Blind Comparison Protocol

1. Ignore grading company, grade, certification number, insert, slab style, holder scratches and holder damage.
2. Evaluate the physical card only. For M01–M10 return **MATCH**, **POSSIBLE MATCH**, **MISMATCH**, or **NOT EVALUABLE**.
3. No feature invention. A feature unresolved in the locked archive cannot later be promoted merely because an unknown image appears to contain it.
4. Negative evidence matters. A missing Grade-A anomaly in an image capable of showing it is strong contradictory evidence.
5. Shared design is weak. Printed artwork, text placement and ordinary production registration cannot by themselves establish specimen identity.
6. State photography limitations including perspective, glare, focus, compression and slab plastic.
7. Final verdict scale: **STRONG MATCH / PROBABLE MATCH / INCONCLUSIVE / PROBABLE MISMATCH / STRONG MISMATCH**.

### Required comparison output

Report each M-number individually, then summarize: Matched / Possible / Mismatched / Not evaluable; strongest positive evidence; strongest contradictory evidence; geometric consistency; evidence quality (LOW/MODERATE/HIGH); identity confidence (LOW/MODERATE/HIGH); and final verdict.
